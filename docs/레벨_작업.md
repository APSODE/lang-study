# 레벨 시스템 작업 (진행 문서)

> 끊겨도 이어서 할 수 있게 만든 체크리스트. **새 세션은 이 문서부터 읽고 첫 번째 미완료 단계를 이어서 한다.**
> 단계 하나가 끝날 때마다 이 문서 상태를 갱신하고 그 단계 파일과 함께 커밋 · 푸시(Co-Authored-By 줄 없이). 배포는 사용자 확인 후.

## 결정 (2026-11-10, 사용자)
- 방식 C: **메인 레벨 = 활동 XP**, 옆에 **트랙별 실력 표시**(익힌 카드 기준).
- 레벨 · 칭호는 **친구에게도 보인다**(친구 목록 · 이번 주 순위).
- 칭호는 유쾌하게(아래 표 그대로 쓴다).

## XP 규칙 (복습 기록에서 계산 — 새 테이블 없이, 기존 사용자도 지금까지 한 만큼으로 시작)
- 복습 정답 +2, 오답 +1, 새 카드(처음 답한 카드) +3
- 그날 할 복습을 다 비운 날 +10 (계산이 비싸거나 기록으로 알 수 없으면 생략하고 기록에 적는다)
- 연속 학습일이 7 · 30 · 100일에 닿은 날 +20 · +50 · +150
- 내가 만든 문제가 공개되면 개당 +5
- 레벨 n 에 필요한 누적 XP = round(50 × (n−1)^1.5) (Lv1 = 0). 상한 없음.

## 칭호 분리 (2026-11-10 추가 결정)
- 레벨은 하나(전체 XP) 그대로. **칭호만 일본어 · 영어 두 벌**.
- 어느 칭호를 쓸지: 기본 "자동" = 복습 XP 가 더 많은 쪽(일본어 = kana · kanji, 영어 = toeic · toefl, 항목 · 보너스는 계산에서 뺌, 같으면 일본어). 설정 → 프로필에서 "칭호: 자동 / 일본어 / 영어" 로 고를 수 있다.

## 트랙별 실력 표시 (익힌 카드 = 복습 간격 21일 이상 카드의 노트 수)
- 한자: "익힌 한자 N자" + 그 수가 덮는 가장 높은 JLPT 단계(예: N5 한자를 80% 이상 익히면 "N5 한자 정복") — 계산이 복잡하면 숫자만.
- 가나 · 토익 · 토플 · 항목: "익힌 N개 / 전체 M개".
