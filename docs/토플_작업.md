## 목표
1. 토플 단어 트랙 `toefl` — NAWL(New Academic Word List, NGSL 시리즈) 약 960개, 토익과 같은 연습 방식(뜻 · 예문 빈칸).
2. 새 연습 방식 "철자 채우기"(토플 2026 개편 유형 Complete the Words 식) — 토익 · 토플 단어 모두에 붙인다.

## 단계 (상태: [ ] 할 일 · [~] 진행 중 · [x] 완료)

### A. 병렬 가능
- [x] **A1 코드: toefl 트랙** — core TRACKS/스키마(토익과 같은 필드, `list: 'NAWL'` 허용), 토익 연습 방식(`toeic-meaning`, `toeic-cloze`)이 `toefl` 도 받게(id 는 그대로 두어 기존 카드 기록 유지), 보기 생성(service.ts) · 웹 화면 · 라벨 "토플" · 만들기(직접/파일 `track: "toefl"`) · 가져오기/내보내기 · 테스트. 노트 id `toefl-<단어>`.
  - 완료(2026-11-10): core `TRACKS` 에 toefl, `WORD_TRACKS = ['toeic','toefl']` · `isWordTrack`, 필드는 `ToeicFields` 공용(`list` 에 `'NAWL'` 추가 — toefl 은 NAWL · NGSL · TSL, toeic 은 그대로 TSL · NGSL). 연습 방식 `toeic-meaning` · `toeic-cloze` 가 두 트랙을 받는다(id 그대로). 보기는 트랙별 catalog 라 토플 단어끼리만. 만들기(직접 · 파일 `track: "toefl"`, id `toefl-<단어>`) · 라벨 "토플" · 홈/설정/통계/친구 진도는 `TRACKS` 를 따라 자동. content/toefl.json 이 없어도 시작 · 내보내기 문제없음.
  - C 참고: `content/toefl.json` 노트는 `{ id: "toefl-<단어>", track: "toefl", fields: { word, meaning_ko, pos?, example_en?, example_ko?, list: "NAWL" } }`. 새 카드 순서는 id(알파벳) 순(토익과 같음).
  - D 참고: 새 연습 방식은 `tracks: WORD_TRACKS` 로 등록하면 토익 · 토플 둘 다 붙는다. 웹 화면은 `apps/web/src/drills/index.ts` 의 `DRILL_VIEWS` 에 drill id 로 연결.
- [x] **A2 데이터 준비** — NAWL 원본 받기(출처 · sha256 기록 `content-src/toefl/SOURCES.md`), `tools/toefl/build-base.py` → `content-src/toefl/base.json`, 120개씩 `batches/nawl-NN.json`, 번역 지침 `content-src/toefl/TRANSLATE.md`(토익 지침을 학술 맥락으로 바꿔서), `tools/toefl/merge.py`(토익 merge.py 기반). 기존 토익 단어와 겹치는 표제어 목록을 SOURCES.md 에 적고 제외 여부 결정.
  - 완료: NAWL 1.2 (957개, CC BY-SA 4.0) 받음, 토익과 겹치는 230개를 묶음에서 빼고 727개 중 접두사 조각 10개(par ex mid non pre trans micro semi multi neo, build-base.py DROP)도 빼고 717개를 6묶음으로 나눔 (목록 · 결정은 SOURCES.md).
