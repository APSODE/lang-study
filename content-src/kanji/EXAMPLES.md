# 한자 예시 단어 · 예문 작성 지침 (예문 에이전트용)

입력: `content-src/kanji/batches/<묶음>.ko.json` (한자 · 읽기 · 한국어 뜻이 이미 채워져 있다).
출력: 같은 폴더의 `<묶음>.ex.json` — 입력과 **같은 순서**의 배열, 한 한자당 객체 하나:

```json
{ "kanji": "食", "examples": [ { "word": "食べる", "reading": "たべる", "meaning_ko": "먹다" },
                               { "word": "食事", "reading": "しょくじ", "meaning_ko": "식사" } ],
  "sentence": { "ja": "毎朝七時に朝ご飯を食べます。", "kana": "まいあさしちじにあさごはんをたべます。", "ko": "매일 아침 7시에 아침밥을 먹습니다." } }
```

## examples (1–2개)
- 그 한자가 **들어간** 흔한 일본어 낱말. 그 한자의 JLPT 레벨에 맞는 쉬운 낱말을 먼저. 동사 · 형용사는 사전형.
- `reading`: 낱말 전체의 읽기, **히라가나만** (가타카나 외래어 부분이 있으면 그 부분만 가타카나 허용).
- `meaning_ko`: 짧은 한국어 뜻 하나 (쉼표 없이).
- 国字 · 인명용 한자처럼 흔한 낱말이 없으면 1개만, 정말 없으면 지명 · 인명 낱말도 된다.

## sentence (1개)
- 그 한자가 **반드시 들어간** 자연스러운 일본어 문장 하나, 8–25자 정도, `。` 로 끝냄. 일상 · 학교 · 회사 장면.
- 문장의 다른 한자는 **같거나 쉬운 레벨**의 한자만 쓰고, 어려우면 히라가나로 쓴다. N5 묶음은 N5 한자만.
- 정중체(です · ます)를 기본으로.
- `kana`: `ja` 전체를 읽는 대로 히라가나로 (구두점 `、。` 그대로, 숫자는 읽는 대로 가나로).
- `ko`: 자연스러운 한국어 번역. 일작 문제로 쓰이므로 **이 번역만 보고 원문을 떠올릴 수 있게** 직역에 가깝게.
- 실존 인물 · 회사 이름 금지.

## 형식
- `json.dumps(data, ensure_ascii=False, indent=2) + "\n"`. 입력 파일은 수정하지 않는다.
- 끝나면 `python3 -I tools/kanji/check-examples.py <묶음>` 으로 검사하고 ERROR 를 모두 고친다.
